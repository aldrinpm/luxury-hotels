# Project Overview

## Project Name
Luxury Hotel Booking Website with ThreeUI Integration

## Description
A premium hotel booking website that integrates the Kibori landing page from ThreeUI, adapted for hotel hospitality and accommodation booking.

## Primary Technology Stack
- **Framework**: ReactJS 18
- **Language**: TypeScript
- **3D Graphics**: Three.js (vendored locally, r169)
- **Styling**: CSS3, ThreeUI styles
- **Build Tool**: Create React App (react-scripts 5)
- **Knowledge graph**: Graphify (`graphify-out/`)

## Project Context
The landing page tells the story of a 200-year-old Kyoto woodshop kept whole and reopened as a small luxury hotel. The original ThreeUI component supplies the full-screen 3D narrative; a React application below it delivers the booking experience (search, rooms, amenities, reservation, contact) in the same dark/gold design language.

## Key Objectives
1. Integrate ThreeUI's KiboriLandingPage component into a React application ✅
2. Adapt woodworking content to hotel/hospitality theme ✅
3. Preserve original visual identity, animations, shaders, and interactions ✅
4. Maintain responsive design across all devices ✅
5. Support hotel booking functionality (search, reservations, etc.) ✅ frontend, API stubs in place
